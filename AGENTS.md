# Project guidelines

This is a learning project about the Iowa Gambling Task and reinforcement learning.

The student should write the code himself.

When helping:
- Explain errors before suggesting fixes.
- Prefer hints over complete implementations.
- Do not rewrite whole files unless explicitly asked.
- Do not modify files unless explicitly asked.
- Review code for correctness, readability, and Python best practices.
- Explain new concepts briefly.
- Keep solutions simple and incremental.
- Preserve the scientific assumptions of the Iowa Gambling Task.
- If something is unclear, ask a guiding question rather than implementing it.
